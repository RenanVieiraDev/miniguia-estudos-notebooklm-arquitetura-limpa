Quero um guia de estudos sobre Arquitetura Limpa, organizado de forma progressiva, começando do nível iniciante e evoluindo até uma aplicação prática dos conceitos.

Use as fontes deste projeto para montar um material didático, claro, detalhado e fácil de entender por uma pessoa iniciante.

Estruture a resposta por tópicos principais. Para cada tópico, siga este formato:

 - Nome do conceito
 - Explicação simples e objetiva
 - Por que esse conceito é importante na prática
 - Erros comuns de quem está começando
 - Exemplo prático em TypeScript usando o contexto de uma API de cadastro de usuários
 - Exemplo incorreto, mostrando uma implementação sem boas práticas
 - Exemplo correto, mostrando a aplicação do conceito dentro da Arquitetura Limpa
 - Comparação entre o exemplo incorreto e o correto
 - Resumo final do aprendizado daquele tópico

Quero que os tópicos sejam apresentados em uma ordem de aprendizado progressiva, por exemplo:

 - visão geral da Arquitetura Limpa
 - separação de camadas
 - entidades
 - casos de uso
 - interfaces/adapters
 - controllers
 - repositórios
 - inversão de dependência
 - regras de negócio
 - testabilidade
 - erros comuns ao aplicar Arquitetura Limpa

Regras importantes para a resposta:

explique em linguagem simples, sem assumir conhecimento avançado
seja rico em detalhes, mas didático
use sempre o mesmo domínio de exemplo: API de cadastro de usuários
quando mostrar código, explique o que está errado e o que está certo
prefira exemplos pequenos, claros e evolutivos
mostre como sair de uma implementação acoplada para uma implementação mais limpa
ao final, gere uma trilha prática de estudo com a ordem ideal para aprofundamento

Objetivo final:
quero entender os fundamentos da Arquitetura Limpa e conseguir aplicar cada conceito de forma prática em TypeScript, de um jeito progressivo e fácil de acompanhar.
